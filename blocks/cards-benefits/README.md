# Cards Benefits

A centered grid of benefit items, each with a colored icon, a heading, and a short description. Renders
as three columns on desktop, two on tablet, one on mobile.

- **Base block:** `cards`
- **Canonical model:** standalone

## Authoring

Create a block named **Cards Benefits**. Add one row per benefit, with an icon and the text:

| Cards Benefits | |
| --- | --- |
| ![](./media/speed.png) | **Unmatched Speed**<br>Optimized to make your content shine, and fast. |
| ![](./media/scale.png) | **Content At Scale**<br>Author, publish, and develop quickly. |
| ![](./media/composable.png) | **Composability is Here**<br>Integrate the tech you already own. |

Put a section eyebrow/heading (e.g. "Benefits" / "Made to meet your every CMS need") as default content
above the block.

### Content (per row)

- **Icon** — a small image in its own cell.
- **Body** — a heading and a short description paragraph.

## Supported variations

_None._

## Notes

The CSS is structural only — brand colors, icon coloring, and typography are applied during the design pass.
